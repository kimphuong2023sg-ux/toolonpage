## 🚀 Khởi Động Nhanh

### 1. Chạy Dưới Máy Local
```bash
# Cài đặt toàn bộ dependencies
npm install
npm run install:all # hoặc cài riêng lẻ client và server

# Khởi chạy đồng thời cả Server và Client
npm run dev
```
- Client chạy tại: `http://localhost:5173`
- Backend API chạy tại: `http://localhost:5000`
