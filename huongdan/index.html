2. Cài Đặt & Kết Nối Website WordPress

2.1. Kết nối tự động qua 1-Click (Khuyên dùng)

  1. Bấm vào nút 🌐 Quản Lý Website trên thanh điều hướng.
  2. Tại khung Thêm Website Mới, nhập:
    • Tên website: Tên gợi nhớ (VD: Juegalotto 365).
    • Địa chỉ URL: Link trang chủ (VD: https://juegalotto365.com).
    • Tài khoản & Mật khẩu Admin: Tài khoản quản trị quyền Administrator của WordPress.
  3. Bấm nút màu xanh: 🚀 Tự Động Cài & Active Plugin.
  4. Hệ thống tự động thực hiện: Đăng nhập WordPress ➔ Tải bản ZIP mới nhất lên ➔ Kích hoạt Plugin ➔ Tự động trích xuất Secret API Key và hoàn tất kết nối chỉ trong 5-10 giây!
💡 Nâng cấp Plugin nhanh: Đối với website đã kết nối nhưng cần cập nhật phiên bản mới, chỉ cần bấm nút 🔄 Nâng Cấp Plugin ngay tại dòng website đó.

2.2. Kết nối thủ công bằng file ZIP

  1. Bấm nút 📥 Tải Plugin (.zip) trong cửa sổ Quản Lý Website để tải file toolonpage-connector.zip.
  2. Đăng nhập vào /wp-admin của website WordPress mục tiêu.
  3. Vào Plugins ➔ Add New ➔ Upload Plugin ➔ Chọn file zip và bấm Install Now ➔ Activate.
  4. Vào menu Tool OnPage ở thanh menu trái WordPress để copy chuỗi Secret API Key.
  5. Quay lại Tool OnPage: Bấm nút 🔑 Dán Key tại website tương ứng để lưu kết nối.

3. Quy Trình Kiểm Tra Trùng Lặp Nội Dung (Spineditor Auto-Bot)

3.1. Cài đặt Chrome Extension (Chế độ Nhà phát triển)

  1. Bấm nút 🤖 Hướng Dẫn Bot Spineditor trên thanh menu.
  2. Bấm nút 📦 Tải Bộ Extension (.ZIP) (hoặc tải trực tiếp tại: https://api.toolseo.uk/api/spineditor/download-extension).
  3. Giải nén file `.zip` vừa tải ra một thư mục cố định trên máy tính (VD: D:\ToolOnpage-Extension).
  4. Mở trình duyệt Chrome/Edge ➔ Gõ đường dẫn: chrome://extensions/.
  5. Gạt bật công tắc "Chế độ dành cho nhà phát triển" (Developer mode) ở góc trên bên phải.
  6. Bấm nút "Tải tiện ích đã giải nén" (Load unpacked) ➔ Chọn thư mục vừa giải nén.
  7. Biểu tượng ToolOnpage Spineditor Bot ⚡ sẽ xuất hiện trên thanh tiện ích của trình duyệt.

Bấm vào biểu tượng tiện ích ToolOnpage Bot ⚡ trên thanh tiện ích hoặc bảng điều khiển nổi:

⚠️ TUYỆT ĐỐI KHÔNG CHỌN "LOCAL":
Nếu bạn để nhầm ở mục Local (localhost), bot sẽ không thể kết nối tới máy chủ chung để lấy danh sách bài viết từ hàng đợi và không thể lưu kết quả kiểm tra trùng lặp về hệ thống!

Các thông số thiết lập chi tiết:

  • Địa chỉ API ToolOnpage: Bấm nút 🌐 Server ➔ Tự động nhận link https://api.toolseo.uk.

  • Nghỉ (giây) / Delay Seconds: Điền từ 5 đến 6 giây để Spineditor hoạt động mượt mà, tránh bị giới hạn tần suất gửi yêu cầu.
