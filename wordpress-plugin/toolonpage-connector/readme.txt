Cầu nối kết nối trực tiếp, ổn định 100% giữa Tool OnPage SEO và WordPress.

== Description ==

Plugin này cung cấp cổng kết nối bảo mật qua Secret API Key giúp Tool OnPage:
* Gán Ảnh đại diện (Featured Image) chuẩn xác 100% bằng hàm WordPress Core.
* Tự động tải ảnh (Sideload Image) vào thư viện WordPress Media Library.
* Đồng bộ 100% các cấu hình Rank Math SEO (Focus Keyword, SEO Title, Description, Pillar Content, Score).
* Tự động dọn dẹp các ảnh trùng lặp trong Media Library mà không ảnh hưởng đến nội dung bài viết.

== Installation ==

1. Tải file `toolonpage-connector.zip`.
2. Truy cập vào trang quản trị WordPress: **Plugins > Add New (Cài mới) > Upload Plugin (Tải plugin lên)**.
3. Chọn file `toolonpage-connector.zip` và bấm **Install Now (Cài đặt ngay)**.
4. Bấm **Activate Plugin (Kích hoạt plugin)**.
5. Vào menu **Tool OnPage** ở cột bên trái của WP Admin, sao chép **Secret API Key** và dán vào Tool OnPage.
