1. Tổng Quan Hệ Thống

Tool OnPage là phần mềm all-in-one chuyên nghiệp hỗ trợ vận hành và tối ưu hóa nội dung SEO WordPress:

  • Tự động kiểm tra trùng lặp Spineditor: Tích hợp Bot Extension và Tampermonkey quét tự động qua SCheckPro, đo độ Unique %, bôi đỏ câu trùng lặp kèm link đối thủ và lọc bỏ domain của chính mình.
  • Biên tập & Xuất bản chuẩn SEO Rank Math 100/100: Tính toán điểm số thời gian thực, đồng bộ Focus Keyword, Title, Meta Description, Slug, Canonical URL và Schema.
  • Quản lý Media thông minh: Quét thư viện ảnh từ WordPress Core, tự động gán Featured Image, đối soát tránh nhân bản các file ảnh trùng lặp (-1.jpg, -2.jpg).
  • Bảo mật & Phân quyền: Quản lý đa tài khoản (Admin/Member), bảo vệ bằng IP Whitelist, cơ chế chống dùng chung tài khoản (đá phiên tức thì).

2. Cài Đặt & Kết Nối Website WordPress

2.1. Kết nối tự động qua 1-Click (Khuyên dùng)

  1. Bấm vào nút 🌐 Quản Lý Website trên thanh điều hướng.
  2. Tại khung Thêm Website Mới, nhập:
    • Tên website: Tên gợi nhớ (VD: Juegalotto 365).
    • Địa chỉ URL: Link trang chủ (VD: https://juegalotto365.com).
    • Tài khoản & Mật khẩu Admin: Tài khoản quản trị quyền Administrator của WordPress.
  3. Bấm nút màu xanh: 🚀 Tự Động Cài & Active Plugin.
  4. Hệ thống tự động thực hiện: Đăng nhập WordPress ➔ Tải bản ZIP mới nhất lên ➔ Kích hoạt Plugin ➔ Tự động trích xuất Secret API Key và hoàn tất kết nối chỉ trong 5-10 giây!
💡 Nâng cấp Plugin nhanh: Đối với website đã kết nối nhưng cần cập nhật phiên bản mới, chỉ cần bấm nút 🔄 Nâng Cấp Plugin ngay tại dòng website đó.

2.2. Kết nối thủ công bằng file ZIP

  1. Bấm nút 📥 Tải Plugin (.zip) trong cửa sổ Quản Lý Website để tải file toolonpage-connector.zip.
  2. Đăng nhập vào /wp-admin của website WordPress mục tiêu.
  3. Vào Plugins ➔ Add New ➔ Upload Plugin ➔ Chọn file zip và bấm Install Now ➔ Activate.
  4. Vào menu Tool OnPage ở thanh menu trái WordPress để copy chuỗi Secret API Key.
  5. Quay lại Tool OnPage: Bấm nút 🔑 Dán Key tại website tương ứng để lưu kết nối.

3. Quy Trình Kiểm Tra Trùng Lặp Nội Dung (Spineditor Auto-Bot)

3.1. Cài đặt Chrome Extension (Chế độ Nhà phát triển)

  1. Bấm nút 🤖 Hướng Dẫn Bot Spineditor trên thanh menu.
  2. Bấm nút 📦 Tải Bộ Extension (.ZIP) (hoặc tải trực tiếp tại: https://api.toolseo.uk/api/spineditor/download-extension).
  3. Giải nén file `.zip` vừa tải ra một thư mục cố định trên máy tính (VD: D:\ToolOnpage-Extension).
  4. Mở trình duyệt Chrome/Edge ➔ Gõ đường dẫn: chrome://extensions/.
  5. Gạt bật công tắc "Chế độ dành cho nhà phát triển" (Developer mode) ở góc trên bên phải.
  6. Bấm nút "Tải tiện ích đã giải nén" (Load unpacked) ➔ Chọn thư mục vừa giải nén.
  7. Biểu tượng ToolOnpage Spineditor Bot ⚡ sẽ xuất hiện trên thanh tiện ích của trình duyệt.

3.2. Cấu hình Extension

Bấm vào biểu tượng tiện ích ToolOnpage Bot ⚡ và thiết lập 3 thông số:

  • Địa chỉ API ToolOnpage:
    • Bấm nút 🌐 Server để dùng: https://api.toolseo.uk
    • Bấm nút 💻 Local nếu chạy tool trên máy cá nhân: http://localhost:5000
  • Domain loại trừ (Excluded Domain): Nhập tên miền của bạn (VD: juegalotto365.com). Bot sẽ tự động bỏ qua không tính trùng lặp đối với các bài đã đăng trên chính website này.
  • Thời gian nghỉ (Delay Seconds): Giữ mặc định 6 giây giữa các bài để đảm bảo Spineditor xử lý ổn định.
  • Bấm 💾 Lưu Cấu Hình.

3.3. Nạp bài viết Word (.docx) vào hàng đợi

  1. Bấm nút 📄 Nạp Hàng Loạt DOCX trên Tool OnPage.
  2. Kéo thả 1 hoặc nhiều file .docx bài viết vào khung tải lên.
  3. Hệ thống tự động phân tách Tiêu đề, H1, H2, H3 và nội dung.
  4. Bấm 🚀 Đưa Vào Hàng Đợi Quét Trùng Lặp.

3.4. Vận hành Bot quét tự động

  1. Truy cập trang Spineditor: https://spineditor.com/kiem-tra-trung-lap-noi-dung và đăng nhập tài khoản.
  2. Bảng điều khiển nổi của Bot sẽ tự động xuất hiện ở góc dưới phải và hiển thị số lượng bài đang chờ.
  3. Bấm nút 🚀 BẮT ĐẦU QUÉT TỰ ĐỘNG.
  4. Bot sẽ tự động nạp từng bài viết ➔ Bấm nút kiểm tra SCheckPro ➔ Trích xuất tỷ lệ % Unique và danh sách câu trùng lặp ➔ Tự động gửi kết quả về Server ToolOnpage để lưu trữ mà không cần người dùng can thiệp!

3.5. Xem chi tiết câu trùng lặp & Tải báo cáo

  • Tại danh sách bài viết trên Tool: Cột Spineditor sẽ hiển thị huy hiệu:
    • 🟢 Xanh lá (85% - 100%): Đạt tiêu chuẩn Unique cao, có thể xuất bản ngay.
    • 🟡 Vàng (70% - 84%): Cần sửa lại một vài câu.
    • 🔴 Đỏ (< 70%): Trùng lặp nhiều, bắt buộc phải viết lại.
  • Bấm nút 👁️ Xem Trùng Lặp: Toàn bộ các câu bị trùng lặp sẽ được bôi đỏ nổi bật kèm đường link website đối thủ đang có câu tương tự.
  • Bấm nút 📥 Tải File Câu Trùng Lặp (.txt) để xuất riêng các câu lỗi gửi lại cho Writer biên tập lại.

4. Biên Tập & Xuất Bản Chuẩn SEO Rank Math 100/100

Khi bấm nút ✏️ Soạn Thảo & Tối Ưu trên bài viết:

  • Quản lý Media thông minh: Khi tải ảnh, hệ thống tự động đối soát với thư viện WordPress Media Library. Nếu ảnh đã có trên hosting, công cụ sẽ dùng lại URL gốc, không tải lên nhiều lần làm sinh ra các ảnh rác đuôi -1.jpg, -2.jpg. Có nút 🧹 Dọn Dẹp Ảnh Trùng để làm sạch hosting.
  • Gán ảnh đại diện (Featured Image): Chọn ảnh bất kỳ trong bài bấm 🖼️ Đặt Làm Ảnh Đại Diện, plugin sẽ gọi trực tiếp hàm WordPress Core để gán chính xác trên mọi Theme.
  • Tối ưu Rank Math SEO theo thời gian thực:
    • Điền Từ khóa chính (Focus Keyword): Điểm số SEO (0-100) sẽ tính toán tức thì theo thuật toán Rank Math.
    • Tối ưu Tiêu đề SEO, Mô tả Meta (140-160 ký tự), Slug đường dẫn tĩnh và Canonical URL.
  • Xuất bản trực tiếp: Chọn trạng thái Bản nháp (Draft) hoặc Xuất bản (Publish) ➔ Bấm 🚀 Xuất Bản Chuẩn SEO Lên WordPress. Bài viết và toàn bộ metadata Rank Math sẽ hiển thị trên web sau 2-3 giây.

5. Quản Trị Hệ Thống & Bảo Mật (Admin Portal)

  • Phân quyền thành viên: Tài khoản Admin (toàn quyền cấu hình bảo mật, quản lý user) và Member (nhân viên dùng tool làm việc).
  • Cơ chế bảo vệ IP Whitelist: Khi bật tính năng này, chỉ những địa chỉ IP được cấp phép mới có thể đăng nhập vào Tool, ngăn chặn triệt để nguy cơ lộ mật khẩu hoặc truy cập từ bên ngoài.
  • Chống dùng chung tài khoản (Single Session): Mỗi tài khoản chỉ được đăng nhập trên 1 thiết bị tại một thời điểm. Nếu có người thứ 2 đăng nhập, máy cũ sẽ bị đá văng ra ngay lập tức.
  • Nhật ký kiểm toán (Audit Logs): Quản trị viên có thể theo dõi ai đang online, ai vừa đăng bài nào, tải bao nhiêu ảnh kèm thời gian và IP chi tiết.
